# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

Source material for, and eventually the code of, the **claude.formosa** community website. claude.formosa is a Claude user group in Taiwan that holds a free monthly meetup in Hualien (花蓮雲基地) on the last Friday of each month, plus occasional Hsinchu meetups. The site will be hosted from this repository with **GitHub Pages** (remote: `samsonchen/claude-formosa-demo1`, so it will be served under the `/claude-formosa-demo1/` subpath; use relative asset paths).

## Site code and build

The site is a static site generated by one Node script (no dependencies, Node 18+):

- `site/build.mjs`: all page content (Chinese and English) plus the HTML templates. Edit event data, copy, and the next meetup date (`NEXT`) here.
- `site/static/`: CSS, JS, images, the Discord QR code, and videos. Copied to `docs/assets/` on build.
- `docs/`: the generated output that GitHub Pages serves (Pages source: `main` branch, `/docs` folder). Don't edit it by hand; rebuild instead.

Commands:

- Build: `node site/build.mjs` (empties and regenerates `docs/`).
- Preview locally: `cd docs && python -m http.server 8765`, then open http://localhost:8765/.
- Deploy: commit `site/` and `docs/` and push to `main`; Pages redeploys automatically.

Pages: Chinese at `docs/index.html` and `docs/events/<date>.html`, English at `docs/en/...`. To add an event, add an entry at the top of `EVENTS` in `site/build.mjs` with both `zh` and `en` content, put its photos in `site/static/img/`, and rebuild.

The design source is the claude.ai Design canvas "claude.formosa Website". Videos must be H.264 MP4 with the `moov` box at the front (faststart) so they start playing before they finish downloading.

## Key input files

- `claude.formosa-web.md`: **the website spec. Read it before any site work.** Main requirements:
  - Responsive for desktop and mobile; bilingual (Traditional Chinese and English).
  - Show the Discord link with a QR code on desktop only. Hide the QR code on mobile.
  - Visual style reference: spacex.com.
  - Every past event gets its own recap page.
  - Use a selection of the photos and videos to balance text and images. You don't need to use every asset.
  - Rewrite the source text for polish and consistency rather than pasting it verbatim. Write in the tone of the `samson-voice` skill.
- `claude.formosa-profile.md`: social links (Discord, Threads, Instagram), organizers, venues, and upcoming event dates.
- `claude.formosa.hualien v2.txt`: the original proposal. It covers the mission, target audience, the standard 18:00–20:00 agenda, and the planned topic schedule. Parts of it are outdated. For example, it says 8/28 had no venue yet, but that event took place. Where the sources disagree, trust `held_events/` and the profile.
- `held_events/YYYY-MM-DD/`: one folder per past event (2026-05-22, 06-26, 07-31, 08-28). These contain posters (`海報/`), photos, and the notices and recaps that were emailed or posted. Naming is inconsistent between folders: the photo folder is `照片/`, `活動照片/`, or `照片-節錄/`; recaps are `event_recap*.md`, `活動摘要_*.md`, or a PDF. Some folders hold several revisions, e.g. `活動摘要_0731.md` and `活動摘要_0731 rev.md`; prefer the `rev` version. Some recaps are already bilingual.
- `videos/`: selected event clips (MP4, about 6–7 MB each).

## Notes for building the site

- The source filenames contain spaces and CJK characters. URL-encode these paths, or copy the assets to ASCII names under the site's asset directory.
- The recaps were written as emails. Do not carry email-only content onto the web pages, such as the unsubscribe footer and its address.
- A meetup is skipped when the last Friday falls on a national holiday: 9/25 (Mid-Autumn Festival) was skipped and 12/25 will be. Take upcoming dates from the profile.

## GitHub access

Use the `gh` CLI for GitHub operations (PRs, issues, Actions runs, Pages settings). Use the GitHub connector tools only when `gh` can't do the task.
